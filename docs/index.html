Nodo IA Caribe · laboratorio TRL 3

Mediciones de punto de partida para IA soberana en el Caribe

Cinco demos reproducibles (voz, nodo sin internet, comparación local vs comercial, WER dialectal y agentes aislados). El código y el protocolo están en GitHub; la interfaz interactiva se ejecuta en tu equipo.

Ver repositorio en GitHub Licencia (FCA)

Esta página es informativa. No ejecuta los demos: hacen falta Python, Ollama y el servidor local descrito en el README. GitHub Pages no sustituye el laboratorio.

Los cinco demos

#Tema
1Voz en español costeño (ASR + LLM + TTS local)
2IA completa sin internet (varios usuarios)
3Modelo local frente a referencia comercial (paquete ciego)
4WER en costeño y palenquero
5Agentes aislados por entidad pública ficticia

Cómo correr el laboratorio en local

  1. Clonar el repositorio e instalar requirements.txt.
  2. ollama pull qwen2.5:3b (demos que usan modelo local).
  3. .venv/bin/python -m interfaz y abrir http://127.0.0.1:8765/.

Instrucciones completas en el README.
