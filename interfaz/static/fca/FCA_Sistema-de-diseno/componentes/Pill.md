# Pill
Pastilla en mono para fechas, códigos, categorías y estados.

- **Azul noche** (`fca-pill`): fondo `surface-navy`, texto `cyan`. Es la del membrete y la presentación.
- **Suave** (`fca-pill fca-pill--soft`): fondo `surface-mist`, texto `brand-blue-strong`, para listas largas.
- Una a tres palabras. No es un botón: no lleva acción.
