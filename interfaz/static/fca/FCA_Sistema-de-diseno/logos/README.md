# Logos

- **fca-lockup-color.png** — la versión principal: las tres barras en `brand-blue` y «FCA / Fundación Código Abierto» en negro. Para fondos claros.
- **fca-lockup-blanco.png** — las barras en `brand-blue` y el nombre en blanco. Para `surface-navy`, fotos oscuras y el tema oscuro.
- **fca-logotipo-negro.png** — solo el nombre, en negro (archivo de la web, en alta resolución). Para sellos, piezas a una tinta y documentos en blanco y negro.
- **fca-isotipo-barras.png** — solo las tres barras inclinadas. Para favicon, avatares y como motivo gráfico, nunca como reemplazo del nombre en una primera aparición.

Las dos versiones con barras se recortaron del encabezado del membrete. Falta un archivo vectorial (SVG) del logo: cuando exista, reemplaza a estos PNG.

Reglas: deja alrededor un espacio libre igual al alto de una barra; no lo estires, no lo rotes, no cambies el azul de las barras ni pongas el logo de color sobre fondos azules. Tamaño mínimo: 96px de ancho en pantalla y 25 mm en papel.
